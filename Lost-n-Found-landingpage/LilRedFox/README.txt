LILREDFOX — STANDALONE CREATOR LANDING PAGE

This is a static, Cloudflare Pages-friendly, linktree-style creator page. The profile and vertical social-link stack lead; video previews and Fox Finds sit below as secondary sections. It has no build step, server, or API dependency. Upload the contents of this folder as a standalone project, or copy the files into a future creator subfolder within Lost & Found.

Included:
- index.html, styles.css, script.js
- Seven sticker assets used by the auto-rotating hero display and manual sticker picker; Fox Berry art replaces the decorative tails
- The mustache sticker featured only in the Fox Finds merch and affiliate placeholder (excluded from the hero sticker carousel)
- Three optimized thumbnail previews from the supplied channel kit

Brand notes:
- The kit contains a visual font sample (Simple Text.png), but no installable font file. The heading uses a close script-style web font with a local cursive fallback.
- Featured thumbnails and clickable links are editable together in the clearly commented FEATURED VIDEO CARDS block in index.html. Replace each image path and href with the thumbnail and direct video URL; until then, cards open LilRedFox's YouTube channel.
- The page uses original CSS ornament and layout with the supplied stickers and thumbnails. Fox Berry art and the Lost & Found badge are included in assets; the side hearts use a lightweight SVG. No generated background imagery is included.
